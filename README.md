# Russian Railway Comments — Sentiment Analysis

Классификация тональности русскоязычных комментариев о железнодорожном транспорте на `NEGATIVE`, `NEUTRAL`, `POSITIVE`. Сравнение классических моделей и LSTM на небольшом корпусе текстов.

## Эксперименты

- `01_classical_ml.ipynb`: TF-IDF + Multinomial Naive Bayes, Linear SVM, Logistic Regression; baseline наиболее частого класса.
- `02_lstm.ipynb`: Embedding + Bidirectional LSTM на PyTorch.
- Train/validation/test: 60%/20%/20%; выбор модели и эпохи по validation Macro F1.

## Результаты на отложенном тесте

| Модель | Accuracy | Macro F1 |
|---|---:|---:|
| TF-IDF + Logistic Regression | 0.636 | 0.596 |
| Bidirectional LSTM | 0.595 | 0.501 |

**Ограничение оценки.** Метки получены автоматически предобученной RuBERT с использованием вспомогательного кода, **не размечены человеком**. Метрики измеряют согласованность с псевдометками и не доказывают точность определения реальной тональности. Исходные эмодзи при сборе комментариев не сохранились. Для независимой оценки нужна размеченная вручную выборка.

## Данные и запуск

Комментарии VK не включены: отсутствует подтверждение прав на распространение корпуса. Для локального воспроизведения нужен файл `my_comments_labeled_corrected.csv` с колонками `comment_text_clean` и `sentiment_label` (`NEGATIVE`, `NEUTRAL`, `POSITIVE`). Разместить его **вне папки репозитория**:

`~/ML_private_datasets/nlp/my_comments_labeled_corrected.csv`

В Windows `~` означает домашнюю папку пользователя (например, `C:\Users\<пользователь>`).

```bash
pip install -r requirements.txt
```

Запустить ноутбуки из корня проекта в JupyterLab. Сводные результаты и графики сохранены в `results/`, поэтому их можно посмотреть и без исходного CSV.

Код автоматической разметки RuBERT не входит в репозиторий и не заявлен как самостоятельно разработанный компонент.
